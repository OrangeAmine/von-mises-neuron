# VM-N01 interpretation boundaries

## Material Passport

Origin: academic-research-suite / experiment-agent, statistical interpretation.
Task: VM-N01; prospective design and later retained results. This scope note
does not change any frozen scientific criterion. Statistical statements describe
the declared synthetic function population; saved-state replay is distinct from
rerunning a timed optimization experiment.

## Eleven-point statistical fallacy scan

| Check | Assessment for the declared analysis |
| --- | --- |
| Simpson's paradox / aggregation reversal | Report all four periodic families and the smooth guard alongside the equal-family aggregate; a positive aggregate cannot override a failed guard. Label-budget cells remain visible. |
| Ecological fallacy | The independent unit is the target function. Grid points, labels, optimizer steps and initializations are not independent replicates. No individual real-system inference is made. |
| Berkson / sampling selection | Synthetic families and distributions are chosen, so conclusions are conditional on them. No fits are filtered because they perform poorly. |
| Collider bias | There is no post-outcome covariate conditioning or subgroup adjustment. Family and budget strata were specified prospectively. |
| Base-rate neglect | This is squared-error regression, not diagnostic classification. Equal family weighting is a declared estimand, not an estimate of real-world family prevalence. |
| Regression to the mean | V2's observed smooth failure motivates the architecture. Its consumed targets are not reused; fresh functions and fixed controls measure this study's effect. This does not remove dependence on familiar generator families. |
| Survivorship bias | Every planned fit, allowance and failure is retained. A missing/failed cell blocks a complete benefit claim. Earlier good checkpoints cannot relabel a failed attempt as successful. |
| Look-elsewhere effect | Two rates and two hybrid optimizers are the declared adaptive candidate set; three capacity controls are declared. Pilot/development select, confirmation evaluates the locked choices. All arms are reported. |
| Forking paths | Configuration and protocol are hashed before target experiments; scientific sources are frozen before pilot; reserved access requires bound evidence. No threshold, budget or comparator changes follow confirmation access. |
| Correlation versus causation | This is a controlled synthetic approximation comparison. It does not establish physiological/physical mechanisms, identifiable broad/local components, novelty, forecasting superiority or deployment benefit. |
| Reverse causality | No observational directional causal claim is made. Targets are generated independently of model fitting. |

Coverage: **11/11 checked**. Six confirmation functions per family do not yield
a powered population claim. Paired percentile intervals can be unstable at this
sample size and are descriptive. The success rule is an intersection of all
three prespecified contrasts and all guards, not selection of any favorable
interval; optimizer contrasts and other reported cells are descriptive rather
than additional confirmatory successes. There are no post-hoc p-values.

## Regularization and computation

An equal coefficient penalty does not equalize function-space regularization.
Raw Fourier and peak-kernel features have different variances/correlations;
larger dictionaries can have poorly determined coefficients. Equal feature
counts differ from equal fitted-parameter counts. Adaptive kernel-only models
have49 fitted parameters; the adaptive hybrid has37, with16 basis columns.

All models receive the same maximum allowance, but ridge controls stop after
one solve. Report actual runtimes and selected steps. Runtime-limited selection
is hardware/load dependent; its result is not a matched-update comparison.
The narrow static experiment and the one-seed synthetic forecaster integration
check answer different questions. Passing one cannot rescue failure of the
other, and neither is real-world validation.
